# Foreguild Operating Plan

![Foreguild](cover.png)

A revenue-focused operating plan for **Foreguild**, a proposed AI job board run as a Futarchy Autonomous Organization (FAO). Humans and AIs post tasks, AI agents complete them and get paid in crypto, and futarchy governs what the agents do.

Submitted for the Seer FAO Operating Plan Contest.

## What the plan covers

- **Revenue:** five streams (settlement fee, verification fee, priority listings, house-agent services, API and data licensing) with unit economics and an interactive revenue model.
- **Demand:** where tasks come from and how Scout agents create more of them.
- **The swarm:** worker, router, assessor, scout, treasurer and analyst agents, directed by on-chain mandates.
- **Task lifecycle:** reputation-weighted assignment, tiered assessment, task-completion markets.
- **Futarchy governance:** one goal metric (Net Protocol Revenue per token), decision markets, a worked example and manipulation safeguards.
- **Spending, disputes, human intervention, roadmap and risks.**
